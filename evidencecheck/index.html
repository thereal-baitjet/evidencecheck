What is EvidenceCheck?

EvidenceCheck is a research portfolio project that evaluates whether AI can accurately extract facts from medical study abstracts. It uses TypeSafe Jev (a System One AI model for structured judgments) to verify extractions and compares three review gates:

🚫 No Review

Baseline: extract without any verification

🔍 Deterministic Checks

Schema validation and evidence span verification

🤖 Jev Review Gate

Deterministic checks + Jev confidence thresholding

Research Question: Can Jev identify unsupported extractions, and what fraction of papers need human review?

Key Features

✓ Extract-and-Verify

Deterministic extraction with evidence spans. Jev verifies, doesn't generate.

✓ Offline-First

Works without API keys. Optional live TypeSafe Jev integration.

✓ Transparent

Every extraction cites exact text. No silent substitutions.

✓ Strict Rules

Participant count extraction enforces primary study totals only.

✓ Research Integrity

Locked dev/held-out splits. Frozen prompts. Honest limitations.

✓ Full Documentation

Protocol, annotation guide, test plan, and evaluation template.

Quick Start

1. Clone and Setup

git clone https://github.com/thereal-baitjet/evidencecheck.git cd evidencecheck python3 -m venv venv source venv/bin/activate pip install -r requirements.txt

2. Run Offline Demo (No API Key Needed)

streamlit run src/app.py

Then open http://localhost:8501 in your browser.

3. Run Tests

pytest tests/test_extraction.py -v

4. (Optional) Enable Live Jev

Get an API key from console.typesafe.ai, then:

export TYPESAFE_API_KEY="your-key-here" pip install -r requirements-live.txt # Enable "Live Jev Review" in app settings
